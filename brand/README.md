# Laris logo

The mark is an **L built from server units** stacked like a rack, each with its status light on the right — a monogram that is also a server. Decisions and colours: `docs/identity.md`. These files are generated by `tools/brand/` (`npm run build` there), which also copies the web app's icons into `apps/web/public/`; change the generator, not the files.

## Files

| File                                           | Use                                                                                                                                                                              |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `laris-logo.svg`                               | the full logo (mark + wordmark) on light backgrounds                                                                                                                             |
| `laris-logo-dark.svg`                          | the full logo on dark backgrounds                                                                                                                                                |
| `laris-logo-black.svg`, `laris-logo-white.svg` | one colour, where colour isn't possible (print, engraving, a single-colour badge)                                                                                                |
| `laris-mark.svg`, `laris-mark-dark.svg`        | the mark alone, on light / dark backgrounds (the collapsed sidebar, small spaces)                                                                                                |
| `laris-mark-black.svg`, `laris-mark-white.svg` | the mark alone in one colour                                                                                                                                                     |
| `laris-app-icon.svg`                           | the mark in white on an Indigo violet tile — the source of the icons below                                                                                                       |
| `favicon.svg`, `favicon.ico`                   | the browser tab. Drawn separately on the 16-pixel grid (whole-pixel bars, the lights as one-pixel notches), because the full mark blurs at 16 px. The ICO holds 16, 32 and 48 px |
| `apple-touch-icon.png`                         | iPhone and iPad home screen (180 × 180)                                                                                                                                          |
| `icon-192.png`, `icon-512.png`                 | Android home screen and installing the web app                                                                                                                                   |
| `icon-maskable-512.png`                        | Android's round and squircle crops: a full square with the mark inside the safe zone                                                                                             |
| `laris-avatar.png`                             | profile pictures, e.g. the GitHub organisation (500 × 500)                                                                                                                       |

## Using the logo

- **Colours:** Indigo violet `#544ccb` on light, lavender `#a8afff` on dark; the wordmark `#151628` on light, `#f2f3f9` on dark. Don't recolour it otherwise.
- **Space around it:** at least the height of one server unit on every side.
- **Smallest sizes:** the full logo from 80 px wide; below that use the mark alone; below 24 px use the favicon.
- **Don't** stretch it, rotate it, add effects or gradients, or put it on busy backgrounds.
- **The wordmark** is IBM Plex Sans SemiBold, turned into outlines (no font needed). Its capital height equals the mark's height.
