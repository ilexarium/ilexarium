# Ilexarium logo

The mark is a **terminal screen on two server units**: the screen's top corner cut at an angle, a `>_` prompt in it, each unit with its status light. The cut corner is its signature, kept in every version down to the favicon. Decisions and colours: `docs/identity.md`. These files are generated by `tools/brand/` (`npm run build` there), which also copies the web app's icons into `apps/web/public/`; change the generator, not the files.

## Using the logo

- **Colours:** Indigo violet `#544ccb` on light, lavender `#a8afff` on dark; the wordmark `#151628` on light, `#f2f3f9` on dark. Don't recolour it otherwise.
- **Space around it:** at least the height of one server unit on every side.
- **Smallest sizes:** the full logo from 80 px wide; below that use the mark alone; below 24 px use the favicon.
- **Don't** stretch it, rotate it, add effects or gradients, or put it on busy backgrounds.
- **The wordmark** is IBM Plex Sans SemiBold, turned into outlines (no font needed). Its capital height equals the mark's height.
