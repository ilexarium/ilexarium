# @ilex/server

Nest.js backend: REST API (prefix `/api`), WebSocket gateways, auth, Docker control and the command executor.

```sh
npm run dev:server        # from project/ — builds @ilex/shared, then nest --watch on :3000
npm test -w @ilex/server
npm run test:e2e -w @ilex/server
npm run lint -w @ilex/server
```
