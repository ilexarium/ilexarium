# @laris/server

Nest.js backend: REST API (prefix `/api`), WebSocket gateways, auth, Docker control and the command executor.

```sh
npm run dev:server        # from project/ — builds @laris/shared, then nest --watch on :3000
npm test -w @laris/server
npm run test:e2e -w @laris/server
npm run lint -w @laris/server
```
